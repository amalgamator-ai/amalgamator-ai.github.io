Amalgamator covers two kinds of engineering work:

1. **GPU performance analysis** — profile, analyze, and compare GPU traces of LLM inference frameworks, and port optimizations between them.
2. **Bug-fix backporting** — port a fix from one branch to another with a git-first pipeline that exhausts deterministic mechanisms before an LLM touches anything.

Start with [Getting started]({{< relref "/docs/getting-started/" >}}), then pick a workflow.
