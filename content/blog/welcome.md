This site is the public home for **Amalgamator** — LLM-assisted tooling for GPU inference analysis and git-first bug-fix backporting.

## What you will find here

- **[Docs](/docs/)** — guides sourced from the product repository: getting started, GPU workflows, backporting, and CLI reference.
- **[Community](/community/)** — where to file issues, read contributing guidelines, and follow the code of conduct.
- **Blog** — announcements and deeper write-ups as the project grows.

## The idea in one line

Automate the repetitive, evidence-heavy parts of comparing frameworks and keeping fixes in sync — and escalate to a human when the evidence is not enough.

Clone the project on [GitHub](https://github.com/amalgamator-ai/amalgamator) and start with the [getting started](/docs/getting-started/) guide.
